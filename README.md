# TrustLocate 🛡️

**تطبيق مستقل لمشاركة الموقع الجغرافي لمرة واحدة مبني على الموافقة الصريحة والخصوصية الصارمة.**

نظام بديل أخلاقي ونزيه للمواقع التجارية المضللة؛ يتيح إنشاء روابط مشاركة عشوائية ذات صلاحية محدودة، ولا يتم استخراج أو نقل أي إحداثيات إلا بعد نقر المستلم الصريح على زر الموافقة في المتصفح، مع إمكانية حذف البيانات نهائياً في أي لحظة.

---

## 🌟 الميزات والمبادئ الجوهرية (Zero Dark Patterns)

1. **الموافقة الصريحة (Explicit Two-Way Consent):**
   * شاشة المستلم توضح هوية الطالب، الغرض من المشاركة، ومدة الصلاحية.
   * زران متساويان تماماً في الوضوح والحجم: `[أوافق وأشارك موقعي]` و `[رفض ومغادرة بأمان]`.
   * في حال الرفض: لا يتم استدعاء واجهة الموقع `navigator.geolocation` إطلاقاً.
2. **نقطة واحدة فقط (Single Point-in-Time):**
   * مشاركة إحداثية لحظية واحدة بدقة القياس، بدون أي تتبع مستمر أو عمل في الخلفية.
3. **روابط مؤقتة ومشفرة (Auto-Expiring Cryptographic Tokens):**
   * توليد رموز وصول عشوائية 128-بت (`crypto.randomBytes`).
   * انتهاء صلاحية الرابط تلقائياً بعد المدة المحددة (5، 15، 30، 60، أو 120 دقيقة).
4. **سحب الموافقة والحذف الفوري (Instant Data Purge):**
   * يمكن للمستلم أو الطالب في أي وقت النقر على "سحب الموافقة وحذف الإحداثيات"، ليتم مسحها فوراً ونهائياً من الذاكرة وقاعدة البيانات.
5. **دعم كامل للغات وRTL:**
   * العربية (مع محاذاة RTL وخط Tajawal الحديث).
   * الفرنسية (Français) والإنجليزية (English).
6. **خريطة تفاعلية مفتوحة المصدر:**
   * مدمجة عبر Leaflet و OpenStreetMap بدون مفاتيح تجارية مغلقة، مع دائرة توضح دقة القياس.
7. **وضع التجربة الآمن (Mock Mode Toggle):**
   * إمكانية تجربة التدفق بالكامل بإحداثيات افتراضية دون الحاجة لتشغيل الـ GPS الفعلي.

## 🚀 أوامر التشغيل السريع

### 1. تشغيل خادم الـ API (الخلفية):
```bash
npm run server
```
*يعمل على المنفذ: `http://localhost:3001`*

### 2. تشغيل واجهة المستخدم (Vite Frontend):
```bash
npm run dev
```
*تعمل على المنفذ: `http://localhost:3000`*

### 3. تشغيل اختبارات القبول الآلية:
```bash
node test_e2e.js
```

## 🧪 نتائج اختبارات القبول (Acceptance Tests)
تم تنفيذ جناح الاختبارات الآلية بنجاح 100%:
* ✅ **حالة الموافقة الصريحة:** تسجيل نقطة الموقع لمرة واحدة فور إعطاء الإذن.
* ✅ **حالة رفض الإذن:** الرفض الآمن دون تسجيل أي إحداثيات وتحويل الحالة إلى `REJECTED`.
* ✅ **حالة انتهاء الصلاحية:** إغلاق الرابط فور مرور النافذة الزمنية المحددة.
* ✅ **حالة سحب الموافقة:** مسح الإحداثيات نهائياً وتحويلها إلى `NULL` في الذاكرة.
* ✅ **حظر التسجيل في السجلات (Zero Logging):** منع تخزين الإحداثيات في سجلات الخادم.
